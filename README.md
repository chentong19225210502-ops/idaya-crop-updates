# 衣搭雅裁图工具 · 在线更新

此仓库提供版本清单和程序更新包。当前已开通自定义尺寸支线（custom-size），最新版本为 V1.0.9。

## 使用

首次请完整解压 V1.0.9 完整运行包，双击对应 EXE。V1.0.9 的“检查更新”位于下方操作区左侧，V1.0.8 仍在右上角；点击即可检查本支线；也可在更新窗口开启或关闭启动检查。当前 V1.0.9 应显示已是最新版本，V1.0.8 用户检查后会提示升级到 V1.0.9，后续发布更高版本后继续提示下载并安装。

Releases 中的小更新 ZIP 仅供已有完整运行环境的软件升级使用，不能单独作为完整软件运行。更新会保留图片、个人设置和 AI 模型；下载和内部文件校验通过后安装，写入或启动检查失败时恢复旧文件。

## 发布规则

- 支线版本清单：`custom-size.json`；主线尚未开通。
- 先上传并核验 Release 附件，再提交版本清单。
- 清单中的大小和 SHA-256 必须与附件一致，下一版必须使用更高版本号。
- 本仓库不保存用户图片、个人设置、账号凭据、AI模型和运行环境。

原程序源码仓库保持私有。公开更新 ZIP 内含可执行文件和程序脚本。
